# 🤖 Telegram Bot с капчей

## 🚀 Бесплатный хостинг 24/7 — Render.com

### Шаги для деплоя:

1. **Зарегистрируйся на Render.com** (бесплатно)
2. **Создай новый Web Service**
3. **Подключи GitHub репозиторий**
4. **Render автоматически развернёт бота**

### Конфигурация:
- **Токен бота:** хранится в переменных окружения
- **Автоперезапуск:** Render перезапускает при сбое
- **Логи:** доступны в панели Render
- **Мониторинг:** встроенная проверка здоровья

### Команды бота:
- `/start` — активировать капчу
- `/status` — статус (только админ)
- `/restart` — перезапуск (только админ)

### Локальный запуск:
```bash
npm install
npm start
```

### Переменные окружения:
- `BOT_TOKEN` — токен Telegram бота
- `NODE_ENV` — production/development
