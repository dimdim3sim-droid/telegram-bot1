# 🚀 Масштабное обновление Telegram-бота

## Стадия 1: Mini App (настоящее WebApp)
- Создать `webapp/index.html` — полноценное SPA с Telegram WebApp SDK
- Дашборд: баланс, статистика, профиль, заказы
- Админ-панель с графиками, таблицами пользователей/заказов
- Подключить к боту через `WebApp` кнопки

## Стадия 2: Новые задания и рефералы
- Задания: пригласить N друзей, выполнить M заказов, купить титул
- Автоматическая проверка и начисление монет
- Реферальная ссылка с трекингом

## Стадия 3: Заказы за игровую валюту
- Выбор валюты при создании заказа (Stars / Coins)
- Отдельный список заказов за монеты
- Выплата монетами исполнителю

## Стадия 4: Новости
- Кнопка «📰 Новости» для всех
- Админ: `/news <текст>` — рассылка всем пользователям
- Сохранение истории новостей

## Стадия 5: Интернет (видео-платформа)
- Создание видео за монеты/Stars
- Поиск по названию
- Инвестиции в видео → поднятие в рекомендациях
- Профили пользователей (кроме админа — аноним)
- Просмотр чужих профилей

## Стадия 6: Донаты и почта
- Донат игровой валюты другому пользователю
- Почта: получение писем с подарками (монеты, титулы)
- Отправка подарков админом

## Стадия 7: Рыбалка (mini-game)
- 40+ видов рыб с редкостями (обычная → божественная)
- КД 12 часов на пользователя
- Ловля → получение рыбы → инвентарь
- Аукцион: выставление рыбы за Stars/Coins
- Экономика 1:1: Stars идут в бота, продавец получает Coins

## Стадия 8: Интеграция и тестирование
- Объединить всё в bot.js
- Сохранение state в data.json
- Проверка синтаксиса и запуск
